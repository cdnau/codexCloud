# Multimedia Study Room

เว็บไซต์อ่านทบทวนภาษาไทย บทที่ 6–12 พร้อมแบบทดสอบปรนัย 52 ข้อ เฉลย และฝึกอัตนัย Sound/Audio, Hypermedia และ Streaming

## Run

Download `index.html` and open it in a browser. The site is self-contained; no installation or build is required. Reading progress and essay drafts are saved in browser localStorage.

## GitHub Pages

In repository Settings → Pages, choose Deploy from a branch, select `main` and `/ (root)`, then Save. Once deployment succeeds, the expected URL is https://cdnau.github.io/codexCloud/.

## Content

- Seven chapter pages with search and reading progress
- 52 multiple-choice practice questions, chapter filtering, scores and explanations
- Four essay practice prompts with sample answers and self-assessment checklists
- Responsive layout and chapter printing

Practice questions are not confirmed exam questions. Original lecture PDF files are not included in this public repository; they remain in the downloadable study bundle supplied in the chat.

JavaScript syntax and the 52-question bank structure were checked. Interactive browser QA has not yet been performed.
